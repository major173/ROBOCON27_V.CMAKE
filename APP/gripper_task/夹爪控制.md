# 夹爪控制

## 文件与职责

| 文件 | 职责 |
| --- | --- |
| `gripper_task.h / .cpp` | 公共动作接口、IM6014 通信任务；USART2 / RS485_1，ID 0 |
| `GripperController.hpp / .cpp` | 归零、开口定位、接触搜索、力矩保持 |
| `gripper_config.hpp` | 夹爪机械参数及各阶段参数 |
| `belt_config.hpp / belt_task.cpp` | 两条传送带参数、位置 P + 速度 PI、松手保持 |
| `robot_com/com_config.cpp` | CAN2 收发、Xbox 接收与夹爪按键映射 |
| `control_task/control_task.cpp` | Y/A 转为传送带方向请求 |
| `robot_task/robot_task.cpp` | 注册正式控制任务 |

已移除 `watch_task`、VOFA 打印、Ozone 测试数组及输入来源/使能开关。`debug_task` 文件保留供后续调试使用，当前没有注册运行；正式控制不依赖它。

## 机械参数

| 项目 | 当前值 |
| --- | --- |
| 夹爪最大开口 / 归零宽度 | 412 mm |
| 预夹开口 | 350 mm |
| 搜索最小开口 | 200 mm |
| 开口到位误差 | 10 mm |
| 开口换算 K | 33.1596 mm/rad，整个开口变化量 |
| 夹爪方向 s | −1，电机正转使开口减小 |
| 传送带换算 | 11.693 mm/rad，实测输出轴约 490° 对应带移动 100 mm |
| 左带 / 右带 | CAN2：ID 1 / ID 2，反馈 0x201 / 0x202，共用控制帧 0x200 |
| 向上方向 | 左电机负转，右电机正转 |

夹爪开口模型：`w = 412 - 33.1596 × (θ - θ_home)`，θ 为 IM6014 输出轴弧度。归零记录当次外止挡角度，不写死上位机读到的绝对角度，不重复换算电机内部减速比。

传送带位置来自 M2006 输出轴累计角度；底层位置单位为度、速度为 rad/s，APP 换算为带的 mm。物块与带存在滑动，所以这些 mm 仅描述带的运动，不代表物体位移；当前不提供“物体上升指定距离”接口。

## 当前控制参数

IM6014 参数集中在 `gripper_config.hpp`，全部为输出轴单位。

| 阶段 | 速度 / 力矩 | Kp | Kd | 完成条件 |
| --- | --- | --- | --- | --- |
| Homing | 向外 −0.4 rad/s | 0 | 10 | 开方向力矩 ≥2.6 N·m，且低速连续确认 |
| Moving | 开口参考 60 mm/s | 7 | 6 | 距目标开口 ≤10 mm |
| Search | 向内 +0.3 rad/s | 0 | 10 | 闭方向力矩 ≥2.0 N·m，且低速连续确认 |
| Holding | 力矩目标 5 N·m，变化率 2 N·m/s | 0 | 0 | 力矩参考到达目标后持续保持 |

接触确认共用：实际速度绝对值 ≤0.15 rad/s，连续 **5 个新反馈帧**满足条件。帧数由有效反馈累计，旧数据不重复计数。Moving 同时输出平滑位置参考和对应速度参考。

两路 M2006 参数集中在 `belt_config.hpp`：

| 参数 | 当前值 / 单位 |
| --- | --- |
| 速度 PI：Kp / Ki / Kd | 3000 / 100 / 0 |
| 速度输入 | 输出轴 rad/s；内部按实际经过时间积分 |
| PI 输出上限 / 积分上限 | 3000 / 500，C610 电流指令单位 |
| 位置 P | 3 s⁻¹ |
| 上下移动参考速度 | 100 mm/s |
| 位置环输出速度上限 | 500 mm/s |

每 1 ms 调度：`目标速度 = 限幅(3 × 位置误差, ±500)`，再换算为各电机输出轴 rad/s，交给速度 PI。Y/A 按住时共同增加两侧位置参考；松手或换向时各自锁存实际位置，速度积分保留。首次 Up/Down 前为零电流；首次 Up/Down 建立本地参考和 PID 时间基准，之后 Hold 持续保持。

两侧采用相同参考增量、各自闭环，不额外加入交叉同步补偿。500 mm/s 是位置环输出上限，按住运行的参考速度仍为 100 mm/s。

## 动作过程

- 上电首次有效反馈，或收到 `Home`：向外归零 → 记录角度 → `Ready`。
- `Grip`：Moving 到预夹 350 mm → Search 向内找物体 → 接触后进入 Holding，从接触力矩逐渐到 5 N·m。提前接触也进入 Holding；搜索到最小开口附近仍未接触，返回 `Ready / NoObject`。
- `Release`：按 Moving 参数打开至 412 mm → `Ready / Reached`。不重新寻找归零止挡。
- `MoveToWidth`：仅定位开口；闭合途中接触则 `Ready / ContactStopped`，不进入加力保持。
- `Ready` 输出 Stop；`Holding` 持续输出夹持力矩。`Home` 只重建夹爪坐标，不改变传送带方向。

## 自动流程与按键共用接口

在 C++ APP 任务中包含：

```cpp
#include "gripper_task.h"
```

以下各行是独立调用示例，按流程需要选择调用；不是连续执行的动作序列：

```cpp
gripperRequest(GripperAction::Home);               // 机械归零 / 复位
gripperRequest(GripperAction::Grip);               // 预夹 350 mm，保持默认 5 N·m
gripperRequest(GripperAction::Release);            // 打开至 412 mm
gripperRequest(GripperAction::Grip, 350.0f, 4.0f);  // 自定义预夹宽度与保持力矩
gripperRequest(GripperAction::MoveToWidth, 380.0f); // 仅移动夹爪开口
gripperRequest(GripperAction::Stop);               // 取消夹爪动作、卸掉驱动力

gripperBeltMove(BeltDirection::Up);                // 持续上移
gripperBeltMove(BeltDirection::Down);              // 持续下移
gripperBeltMove(BeltDirection::Hold);              // 结束移动并保持当前位置
```

`gripperRequest()` 是异步单槽请求，只保留最新一条；每个流程步骤提交一次，然后等待结果，不要每周期重复提交。`hold_torque_nm=0` 表示使用配置值。未归零时不接受绝对宽度动作。

`gripperStatus()` 返回状态副本。新请求等待执行时 `result=None`，不会把上一次完成结果当成本次结果；`state` 等运行状态由控制任务随后更新。

| 当前步骤 | 等待的 `result` |
| --- | --- |
| 归零 | `GripperResult::Homed` |
| 夹取并逐渐加力 | `GripperResult::HoldTargetReached`，此时仍持续夹持 |
| 松开 / 宽度定位 | `GripperResult::Reached` |
| 其他动作结果 | `NoObject`、`ContactStopped`、`Stopped`、`Rejected` |

例如，流程已收到启动事件后执行一次：

```cpp
gripperRequest(GripperAction::Grip);
// 自动流程转入“等待夹取完成”步骤。
```

在“等待夹取完成”步骤中周期读取：

```cpp
const auto status = gripperStatus();
if (status.result == GripperResult::HoldTargetReached) {
  gripperBeltMove(BeltDirection::Up);
  // 转入下一步骤，离开本分支；后续由传感器或流程事件决定何时 Hold。
}
// NoObject / Rejected 等结果由调用方决定后续动作。
```

传送带方向请求立即替换上一方向，持续到下一次请求；`Hold` 不关闭闭环。夹爪 `Stop` 不等于传送带 `Hold`，需要同时结束两者时分别调用。

按键使用相同入口：LB 短按 Grip、RB 短按 Release、RB 长按 3 秒 Home；Y 上移、A 下移、松手 Hold。新按键事件与自动流程按最后请求生效，中立手柄数据不会重复覆盖自动指令。完整映射见 [xbox.md](../control_task/xbox.md)。

## 后续参数优化

- 修改夹爪参数：`gripper_config.hpp`；修改传送带参数：`belt_config.hpp`，重新编译。
- 传送带先调整速度 PI，再调整位置 P。负载变化后先观察内环跟踪；速度跟踪正常但位置响应慢，再调整位置 P 与参考速度。
- 位置 P 决定位置误差转成多大速度；参考速度决定持续移动节奏；速度上限仅裁剪外环输出，三个参数用途不同。
- 夹爪先确认机械换算与归零，再调 Moving 的 Kp/Kd 和参考速度，最后调 Search 接触参数与 Holding 力矩/变化率。
- 保持力矩是输出轴力矩参考，不是直接测得的物体夹紧力；传送带滑动应通过机构或外部测量解决，不能用调整 mm/rad 冒充物体定位。
